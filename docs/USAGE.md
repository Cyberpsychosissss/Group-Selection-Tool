# ISA302 换组助手 · 使用流程

> 网址：<https://group.wtfareudoing.com>（口令见课程群）。第一次进入每个阶段时页面会自动弹出气泡引导，右上角「引导」可随时重看；站内「使用流程」页和本文内容相同。

几个组的人组成一个**池**，在池里互相勾选想同组的人，系统算出一份移动人数最少的方案，全员同意后**一个一个轮流**去 LM Core 操作。本工具只负责算方案、排顺序、提示每一步；**不登录 LM Core，不收学号和密码**，最终以 LM Core 为准。页面每 2.5 秒自动刷新。

```
登记 → 建池 / 加入 → 到齐 → 互选 → 生成方案 → 确认 → 执行 → 完成
```

## 开始前

- **口令**：课程群里公布，第一次打开网站时输入一次，30 天内不用再输。
- **自己的组号**：LM Core Grouping 页 `Your selection` 显示的组。
- **本组人数**：LM Core Grouping 页表格 `Members` 列里本组的人数。每个组第一个加入池的人要填。
- **一个发起人**：想一起换的几个组里，任选一人创建池、把邀请链接发到各组群。

## 第 1 步 · 登记（每个人，首页）

- 填**代号**（同组同学认得出就行，最多 20 字，不能和别人重复）和**当前组**，点「登记」。
- 一台设备只能登记一个代号；登记后首页底部有「恢复链接」，换设备或清了浏览器数据时用它找回身份，**不要外传**。
- 收到邀请链接的人可以跳过这一步：在邀请页一次完成登记和加入。

## 第 2 步 · 建池与邀请（发起人，首页「创建池」）

- 填本组人数，点「创建」，进入池页面。
- 把池页面顶部的**邀请链接**（点「复制」）发到每一个参与组的群里。
- 一个组只能在一个池里；池至少要有 2 个组。

## 第 3 步 · 加入池（各组每个人）

- 点邀请链接，或在首页「加入池」填邀请码。
- 还没登记的人在邀请页填代号、当前组，本组第一个加入的人再填本组人数，点「登记并加入」。
- 方案生成后就不能再加入。

## 第 4 步 · 等所有组到齐

每个组的**全部**成员都加入后才开放互选。池页面顶部「下一步」会告诉你还差谁。

- **本组人数填错了**：本组任何人在自己组的卡片下方「更正人数」。不能少于已加入的人数。
- **有组员不肯加入**：本组任何人点「+ 占位」，用一个占位代表他。占位占着位置、不参与互选和确认、也不会被移动。

## 第 5 步 · 互选

- 在想同组的人后面点「选」。**双方都选了才算数**，这时两人都会变成绿色的「互选」。看到「对方已选你」说明对方在等你。
- 互选的人连成一个**小队**（A 选 B、B 选 C，则 A、B、C 同队），小队最多 5 人。
- 不想指定的人可以不选，系统会安排；原则是让每个人尽量留在原组。
- 这一阶段随时可以「退出池」。

## 第 6 步 · 生成方案（任何人）

- 三个条件都打勾后，「小队」卡片的「生成方案」按钮可点。
- 系统给每个人分配目标组：小队同组、每组不超过 5 人、**移动的人最少**；人数相同时尽量不让组变小。
- 移动被拆成一对一对的**互换**（你去他的组，他来你的组），凑不成互换的人进空位。
- 如果当前分组已经满足所有互选，会直接完成。

## 第 7 步 · 确认（每个人）

- 每个人看到自己的安排：和谁互换、留在原组、还是进空位；以及新组员名单。
- 点「同意」或「不同意」。**全员同意**才开始执行；**任一人不同意**就退回互选，方案作废，互选保留。

## 第 8 步 · 执行

一对一对地进行。**轮到你时页面会变成绿色的「轮到你」**，没轮到就等着，**不要提前在 LM Core 操作**。

1. 看清提示：取消勾选哪个组、勾选哪个组。点「打开 LM Core Grouping」去操作，点 **Save my choice**。
2. 回到本页点「已在 LM Core 保存」。系统随即通知你的交换对象轮到他。
3. 右下角是和交换对象的一对一对话：预设短语（准备好了 / 稍等 5 分钟 / 收到 / 遇到问题 / 目标组已满），或填上自己的微信号点「加我微信细说」——微信号在两人的浏览器之间端到端加密，服务器只转发密文、不保存。

三种操作：

| 操作 | 什么时候出现 | 在 LM Core 做什么 |
|---|---|---|
| 换组 | 目标组有空位 | 同一次保存里取消旧组、勾选新组 |
| 先退出 | 相关组都满员 | 只取消旧组，暂时无组，等对方换进来 |
| 加入 | 先退出的人，位置空出后 | 只勾选目标组 |

## 第 9 步 · 完成

- 所有人到位后显示「最终分组」。每个人去 LM Core 核对一下 `Your selection`。
- 各组自动释放。想再换一轮，点「退出池」后重新创建或加入新的池即可。

## 遇到问题怎么办

| 情况 | 做法 |
|---|---|
| 有人不同意方案 | 自动退回互选。群里沟通，调整互选后重新生成。 |
| 轮到的人迟迟不操作 | 先用对话发「准备好了」提醒；群里联系。实在等不到，任何人可以在执行卡片下方「执行出了问题？」里**中止执行**。 |
| LM Core 显示目标组已满 | 位置被池外的人占了。点对话里的「目标组已满」告知对方，然后**中止执行**，各组人数会按此刻实际情况重算，再生成新方案。 |
| 有人在 LM Core 上操作错了 | **中止执行**。方案作废、互选保留；已经退出组的人先在 LM Core 加入池内某个组，再在池页面「我已加入该组」更新组号。 |
| 中止后显示「暂无组」 | 这个人现在在 LM Core 上没有组：先加入池内的一个组，再在池页面更新组号，之后才能重新生成方案。 |
| 组号填错了 | 没进池时在首页直接改；已经在池里，先「退出池」再改、再加入。 |
| 换了设备 / 清了浏览器数据 | 打开登记时保存的「恢复链接」。没保存只能找管理员，所以请先保存。 |
| 页面提示「操作太频繁」 | 每台设备每分钟请求有上限，等一分钟再试。 |

## 规则速查

- 每组最多 5 人；只在池内各组之间调人，池外不受影响。
- 代号全站唯一、不区分大小写、最多 20 字；一台设备一个代号。
- 一个组只能在一个池里；池至少 2 个组；全员到齐才开放互选。
- 互选要双向；小队最多 5 人。
- 方案任何人可生成、任何人可否决；执行中任何人可中止。
- 记录的数据：代号、组号、互选、方案、操作记录。不收学号密码，对话不保存，截止后由管理员删除。
