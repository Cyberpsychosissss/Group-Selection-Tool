使用流程

想一起组队的几个人建一个意向组，各自登记现在的组号和那个组的人数。组长宣布到齐后，系统把全站所有意向组放在一起算一份方案： 有组坐得下、或者几个意向组能互换位置，就自动分配；每个人同意后，一个一个轮流去 LM Core 操作。 本工具只负责算方案、排顺序、提示每一步；不登录 LM Core，不收学号和密码，最终以 LM Core 为准。

  1. 登记
  2. 建意向组 / 加入
  3. 宣布到齐
  4. 等待分配
  5. 确认
  6. 执行
  7. 完成

页面每 2.5 秒自动刷新，不用手动刷新。截止 {{ deadline }}。

先说清楚：系统怎么分

  • 不动不参加的人。不会把谁从组里挤出去；只在空位和参加的人之间调。
  • 全站一起算。所有宣布到齐的意向组放在一起：你们组坐不下、他们组也坐不下，但你来我这、我去你那正好——这种互换一次方案里一起完成。
  • 人多的先、移动少的好。一次让最多的人如愿；同样多的人，选移动人数最少的方案。暂时轮不到的意向组继续等，每次人数变化（有人退组、爬虫更新、上一轮完成）都会重新算。
  • 条件不满足就一直等，不会催任何人让位。

开始前

  • 口令：课程群里公布，第一次打开网站时输入一次，30 天内不用再输。
  • 自己的组号：LM Core Grouping 页 Your selection 显示的组。
  • 本组人数：LM Core Grouping 页表格 Members 列里你现在这个组的人数，含不参加本工具的人。每个人都要填自己组的。
  • 一个组长：想一起组队的人里任选一人创建意向组、把邀请链接发给队友。

第 1 步 · 登记

谁：每个人。在哪：首页。

  • 填代号（同组同学认得出就行，最多 20 字，不能和别人重复）和当前组，点「登记」。
  • 一台设备只能登记一个代号；登记后首页底部有「恢复链接」，换设备或清了浏览器数据时用它找回身份，不要外传。
  • 收到邀请链接的人可以跳过这一步：在邀请页一次完成登记和加入。

第 2 步 · 建意向组与邀请

谁：组长。在哪：首页「创建意向组」。

  • 填自己现在这个组的人数，点「创建」，进入意向组页面。
  • 把页面顶部的邀请链接（点「复制」）发给想一起组队的人。邀请码是 8 位，像 K7PQ2XMN。
  • 含组长最多 5 人。不用拉别的组的人——不是让谁让位，是等坐得下。

第 3 步 · 加入意向组

谁：每个队友。在哪：点邀请链接，或首页「加入意向组」填邀请码。

  • 还没登记的人在邀请页填代号、当前组、该组现在的人数，点「登记并加入」。
  • 加入后能看到成员表（每个人现在的组、该组人数）和「坐得下吗」表。自己组的人数填错了随时「更正」。
  • 组长宣布到齐之后就不能再加入。

第 4 步 · 宣布到齐，等待分配

谁：组长。在哪：意向组页面底部「成员已到齐，等待分配」。

  • 按下去之后意向组进入全站统一分配；成员不能再加入 / 退出。要改成员就「重新开放加入」。
  • 「坐得下吗」表按各组人数判断整队能不能搬进某个组：可以 / 还差 n 个空位 / 另一轮进行中。全都"还差"也不用急——和别的意向组互换也算。
  • 页面顶部「下一步」会写明现在在等什么。有组坐得下、或能互换时自动生成方案，直接进入确认。
  • 自己组的人数变了（有人退了、有人进来了），任何成员都可以更正；管理员的爬虫也会定期更新各组人数。

第 5 步 · 确认

谁：这一轮里每个意向组的每个人。在哪：页面「你的安排」。

  • 每个人看到自己的安排：和谁互换、留在原组、还是进空位；以及新组员名单。「组内其他人」是方案里不动的人，不需要表态。
  • 点「同意」或「不同意」。全员同意才开始执行；任一人不同意，这份方案作废：一起分配的意向组退回等待（立刻重新算），不同意那个人的意向组暂停，组长调整后点「重新参与分配」。

第 6 步 · 执行

一对一对地进行，轮到你时页面会变成绿色的「轮到你」，没轮到就等着，不要提前在 LM Core 操作。

  1. 看清提示：取消勾选哪个组、勾选哪个组。点「打开 LM Core Grouping」去操作，点 Save my choice。
  2. 回到本页点「已在 LM Core 保存」。系统随即通知你的交换对象轮到他。
  3. 右下角是和交换对象的一对一对话：预设短语（准备好了 / 稍等 5 分钟 / 收到 / 遇到问题 / 目标组已满），或填上自己的微信号点「加我微信细说」——微信号端到端加密，服务器只转发密文、不保存。

第 7 步 · 完成

  • 所有人到位后显示「最终分组」。每个人去 LM Core 核对一下 Your selection。
  • 涉及的组人数按结果更新，还在等的其他意向组会立刻重新算一次。想再来一轮，点「退出意向组」后重新创建或加入即可。

遇到问题怎么办

情况做法
一直显示「还坐不下」正常，等。有人退出那些组、爬虫更新、或别的意向组和你们能互换时会自动分配。确认一下成员填的人数准不准。
有人不同意方案方案作废，其他意向组马上重新算；不同意那人的意向组暂停，组长调整（改人数 / 换成员）后「重新参与分配」。
轮到的人迟迟不操作先用对话发「准备好了」提醒；群里联系。实在等不到，任何人可以在执行卡片下方「执行出了问题？」里中止执行。
LM Core 显示目标组已满位置被别人占了。点对话里的「目标组已满」告知对方，然后中止执行：各组人数按此刻实际情况记录，再重新分配。
有人在 LM Core 上操作错了中止执行。方案作废；已经退出组的人先在 LM Core 加入一个组，再在页面「我已加入该组」更新组号和该组人数。
中止后显示「暂无组」就是上一条：这个人现在在 LM Core 上没有组，先加入一个组，再在页面更新组号，之后组长「重新参与分配」。
组号填错了没进意向组时在首页直接改；在意向组里等待时也可以在首页改（填上新组的人数）；分配进行中不能改。
换了设备 / 清了浏览器数据打开登记时保存的「恢复链接」。没保存只能找管理员，所以请先保存。
页面提示「操作太频繁」每台设备每分钟请求有上限，等一分钟再试。

规则速查

  • 每组最多 5 人；意向组含组长最多 5 人、至少 2 人。
  • 代号全站唯一、不区分大小写、最多 20 字；一台设备一个代号。
  • 不参加本工具的人不会被移动；只在空位和参加的人之间调。
  • 全站统一分配：如愿的人数最多，其次移动最少；意向组之间可以互换。
  • 方案任何人可否决；执行中任何人可中止。
  • 记录的数据：代号、组号、各组人数、方案、操作记录。不收学号密码，对话不保存，截止后由管理员删除。

常见问题

会把别人从组里挤出去吗？

不会。不参加本工具的人一个都不动，这次没被选中的意向组也不动。

我们组全都坐不下，还有希望吗？

有。系统把全站的意向组放在一起算：你们去他们腾出的位子、他们来你们腾出的位子，一次方案里一起完成。

为什么别的意向组先分配了？

一次只能让部分人如愿时，先满足人多的；同样多就选移动少的。你们会在下一次人数变化时自动重算。

会有人暂时无组吗？

相关组都满时会有人短暂无组（先退出、等对方换进来后加入）；有空位时直接换组，不会无组。

为什么有人要换两次？

几个人的需求连成一个圈且各组都满时，只能分两次对调，中间的人移动两次。很少出现，页面会写清「分 2 步」。

「组内其他人」是什么？

方案里不参加的人：占着位置、不动、不需要表态。他们的人数来自成员填报或爬虫。
